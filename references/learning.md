# 从人机互动积累写作经验

收到用户对稿件的评价、改写或偏好时使用。能力靠后续对话中实际读取、记录和试用积累，不宣称后台自动训练模型或永久记忆。

新反馈归入对应案例；用户更认可的正文原样同步到 approved/ 对应文件并更新本地范例索引 `voice-examples.local.md`，供明确的学习与对照任务使用；开发日志保留追溯入口，不作为唯一存储。先保留案例：原材料与任务、生成原稿、用户原话、用户修改或更认可的版本及来源。原稿不覆盖，未确认定稿仍是草稿。用户称赞、认可阅读感与确认定稿分别记录。

将事实更新、长期偏好和这篇稿子的局部反馈分开。明确的长期要求直接保存；单篇问题先留在案例里。由助手推断的原因标为待验证，不自动变成永久禁令。相同经验合并、修订或撤回，避免历史越积越长。

普通写作使用主入口的精简输入，不自动附加范例或案例记录。执行层将明确且适用于本次的事实、偏好合入摘要；原材料、反馈和失败稿在学习与明确改稿时按需查找。保留用户反馈的方向，结合新材料重新判断，不照搬句式、段数或结论。

需要改Skill时，替换冲突、重复或失效的指导，并用新的直接生成稿检验。记录采用的规则版本；不手工改测试稿来代表Skill效果，不用模型评分宣布达标。新稿未经用户评价不升级为认可范例。

在线可用时按 [在线学习](online-learning.md) 取得真实对照；不可用时用当前材料继续创作，有本地认可样例时按需参考。
