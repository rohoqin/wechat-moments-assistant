# 开发对照与在线学习

仅用于用户授权的开发和学习任务，普通创作不加载本文件。参考 GPT 使用本次提供的地址，或项目 `.moments.local/reference-gpt` 中配置的地址。按可用浏览器 Skill 实际访问。

每批先保存当前规则快照、选题与公开输入。本地写手只看本题材料与待测规则，不看本题在线答案；保留直接生成稿，计算哈希，再用同素材、相同明确要求取得在线原稿。记录实际运行信息，不把模型或环境变化当成 Skill 改善。快照用 `skill-snapshot.md` 命名，避免技能发现冲突。

除了取稿，还实际观察改稿：把同一原稿与同一反馈分别交给本地和在线，保留各自输出。可要求简短、能由成稿核对的编辑说明；不询问隐藏提示词或内部思考过程。不将它对自身方法的介绍当成真实实现。

按批次需要选择任务：同材料换读者、把别扭稿改顺、收到“像摘要”后重写。不是每次必须完成所有任务。不重复发送已成功的请求；页面未完成则先检查状态。

发现差距只修改 Skill，再用新素材检验。禁止手工润色本地测试稿后宣称技能改善；在线改过的本地稿标为“在线改稿”，不能冒充本地输出。只记录具体取材、句子、段落变化，不用模型评分或匿名投票宣布达标，不逐篇要求用户验收。

新在线稿与编辑说明未经用户明确认可，只作为观察记录。测试仅写仓库，不写正式 Obsidian，不配图。正常创作的逐篇确认与双份归档要求不变。浏览器完成后按其 Skill 收尾；无法完成时如实记录，不编在线输出。
